# 🎓 Telegram-бот для Студенческого Научного Общества (СНО)

Асинхронный Telegram-бот, разработанный для автоматизации процессов Студенческого Научного Общества. Бот помогает управлять расписанием лекций, проводить проверочные работы («летучки»), отмечать посещаемость и поддерживать удобную обратную связь между слушателями и организаторами.

## ✨ Основные возможности

Бот поддерживает три уровня доступа: **Студент**, **Лектор** и **Администратор**. 

**Для студентов:**
* 👤 **Профиль:** Регистрация с жесткой валидацией номера группы (формат `ХХХХХХХ/ХХХХХ`) и возможностью редактирования ФИО/группы.
* ℹ️ **Информация и Расписание:** Просмотр списка будущих лекций, времени и места их проведения, а также доступ к GitHub-репозиторию с материалами.
* 📝 **Прохождение летучек:** Поэтапный ответ на вопросы проверочной работы по секретному коду с доски. Встроена защита от повторного прохождения — сдать летучку дважды нельзя.
* 💬 **Обратная связь:** Возможность задать вопрос конкретному лектору (через карточку лекции) или отправить общий вопрос организаторам.
* 🔔 **Уведомления:** Автоматические напоминания о предстоящих лекциях за 3 дня и за 1 день до начала.

**Для лекторов и администраторов:**
* 📚 **Управление лекциями:** Добавление новых занятий, изменение существующих (смена темы, места, времени или лектора) и их удаление.
* ⚙️ **Управление летучками:** 
  * Установка и смена секретного кода доступа.
  * Добавление вопросов (поддерживается массовая загрузка нумерованным списком `1. ... 2. ...`).
  * Массовое редактирование списка вопросов (или удаление всех разом отправкой `0`).
* 📄 **Выгрузка ответов:** Экспорт ответов студентов по конкретной лекции в удобный текстовый файл `.txt`.
* 📊 **Статистика посещаемости:** Генерация `.csv` таблицы (идеально для Excel), где по строкам идут ФИО и группы, а по столбцам — даты лекций с отметками присутствия (1/0).
* 📨 **Система Входящих (Inbox):** Просмотр вопросов от студентов с указанием контекста (к какой лекции вопрос). Возможность ответить студенту прямо через бота (ответ придет ему от имени организатора) и закрыть диалог.
* 👑 **Управление ролями (только для Админов):** Назначение и удаление других администраторов по их `@username`.

## 📖 Руководство пользователя: Что, где и как использовать

### 1. Как провести лекцию и летучку (Гайд для лектора)
1. Нажмите **📚 Управление лекциями** -> **➕ Добавить лекцию**. Введите тему, место и время. Лекция появится в расписании у всех студентов.
2. Перейдите в **⚙️ Управление летучками** -> выберите свою лекцию.
3. Нажмите **🔑 Установить код** и придумайте короткий пинкод (например, `4815`).
4. Нажмите **➕ Добавить вопрос(ы)**. Можно отправить один вопрос, а можно сразу несколько, просто начав каждую строку с цифры:

```text
   1. Что такое градиентный спуск?
   2. В чем разница между линейной и логистической регрессией?
```

5. На занятии скажите студентам код `4815`. Они нажмут **📝 Пройти летучку**, введут код, и бот по очереди задаст им ваши вопросы, параллельно отметив их присутствие.
6. После пары вернитесь в меню летучки и нажмите **📄 Выгрузить ответы**, чтобы получить `.txt` файл с результатами группы.

### 2. Как работать с вопросами студентов (Входящие)

Если студент нажмет "Задать вопрос", у админов и лектора (если вопрос по его лекции) появится уведомление.

1. Зайдите в раздел **📨 Входящие**.
2. Бот покажет список непрочитанных сообщений. Выберите нужное.
3. Вы увидите ФИО, группу студента и текст вопроса.
4. Нажмите **✍️ Ответить** и напишите текст. Бот сам перешлет ваш ответ студенту в личные сообщения. Сообщение пропадет из списка непрочитанных.

### 3. Как получить таблицу посещаемости

1. Нажмите кнопку **📊 Посещаемость** в главном меню.
2. Бот мгновенно сформирует файл `Таблица_Посещаемости.csv`.
3. Скачайте его и откройте в Excel. В таблице будут собраны все пользователи (Студенты, Лекторы, Админы) и их присутствие на каждой лекции за весь сезон.

## 🛠 Технологии

* **Язык:** Python 3.9+
* **Фреймворк:** [aiogram 3.x](https://docs.aiogram.dev/en/latest/) (Асинхронное API Telegram)
* **База данных:** SQLite (через `aiosqlite` для асинхронных запросов)
* **Планировщик:** APScheduler (для отложенных ежедневных уведомлений)

## 🚀 Руководство по установке и развертыванию

Данное руководство описывает полный цикл настройки, локального запуска и подготовки бота к деплою на сервере.

### 🛠 1. Подготовка окружения

Убедитесь, что в вашей системе установлены **Python 3.9+** и **Git**.

Клонируйте репозиторий:
```bash
git clone http://github.com/VitalyKalinsky/spbpu_sno_bot
cd spbpu_sno_bot
```

### 📦 2. Виртуальное окружение и зависимости

Изолированная среда необходима для предотвращения конфликтов версий глобальных пакетов.

**Для Linux / macOS:**
```bash
python3 -m venv venv
source venv/bin/activate
```

**Для Windows:**
```bash
python -m venv venv
venv\Scripts\activate
```

**Установка библиотек:**
Установите зависимости, используя `requirements.txt`:
```bash
pip install -r requirements.txt
```

### 🔐 3. Настройка конфигурации и безопасности

Бот использует чувствительные данные (токены). Они хранятся исключительно в файле `.env`.

1. Создайте в корневой директории проекта файл **`.env`** (вы можете скопировать `.env.example`).
2. Откройте его и добавьте свои данные:
```env
# Основной токен от @BotFather
BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVWxyz

# Telegram ID главных администраторов (узнать через @getmyid_bot)
ANYA_ID=111111111
MY_ID=222222222
```

### 🚀 4. Запуск бота

Убедитесь, что виртуальное окружение активно, и выполните:
```bash
python bot.py
```

*(Для Linux может потребоваться команда `python3 bot.py`).* При первом запуске бот автоматически создаст базу данных `sno_bot.db`.
